# Semeia Leads

SaaS de carteira, leads e pós-venda para distribuidoras que usam o ERP Ctrl-e (Rein). Um produto Grupo Semeia Digital.
Cloudflare Workers + D1, API Hono, SPA React. Veja `CLAUDE.md` e `docs/`.

```bash
npm install
cp .dev.vars.example .dev.vars   # preencha SECRETS_KEY
npm run db:local && npm run dev
```
